Inside V8: how your
JavaScript actually runs

V8 is the engine inside Chrome and Node.js. It turns your source code into machine code, guesses how to make it fast, and cleans up your memory — all while your program is running. Scroll, click, and poke everything below.

04 · Node.js = V8 + libuv

    
Node is V8 with an operating-system sidekick

    
V8 alone can't read files or open sockets — it only knows JavaScript.
       Node.js pairs V8 with libuv, a C library that talks to the OS and runs the
       event loop. Your JS stays single-threaded; the waiting happens elsewhere.


    

      
      

        The whole trick of Node: JS never waits. A file read
        is handed to libuv, your code keeps going, and the finished result comes back later
        as a callback — through the event loop below.
